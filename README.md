# שלט סמסונג 📺

אפליקציה לאנדרואיד ולאייפון שמתחברת ישירות לטלוויזיות Samsung Smart TV (מ-2016 ומעלה) דרך ה-WiFi.

## בנייה
1. ב-GitHub: מאגר חדש בשם `samsung-remote` ← **uploading an existing file** ← גרור את **כל הקבצים** מה-ZIP ← **Commit changes**.
2. **Add file** ← **Create new file** ← שם: `.github/workflows/build.yml` ← הדבק את התוכן של הקובץ `build.yml` ← **Commit changes**.
3. **Actions** ← מחכים ל-✅ ← מורידים מ-**Artifacts**.

## חיבור טלוויזיה
1. באפליקציה: **חפש טלוויזיות ברשת** (הטלוויזיה דלוקה, אותה רשת WiFi).
2. על מסך הטלוויזיה תופיע בקשה מ-"Phone Remote" – בוחרים **אפשר / Allow**. פעם אחת בלבד.

## הדלקה מהטלפון
בטלוויזיה (פעם אחת): **הגדרות ← כללי ← רשת ← הגדרות מומחה ← הפעלה עם נייד** (Power On with Mobile) ← מופעל.
האפליקציה שומרת את כתובת ה-MAC אוטומטית בחיבור הראשון, ומדליקה דרך Wake-on-LAN.
באייפון ייתכן שההדלקה לא תעבוד, כי אפל חוסמת שליחת פקודות כאלה לכל הרשת. כיבוי עובד בכל מקרה.

## FreeTV ו-Cellcom tv
לחיצה על הכפתור (או לחיצה ארוכה) ← **הצג את האפליקציות בטלוויזיה** ← בוחרים מהרשימה.

## אם הטלוויזיה חסמה את הטלפון
הגדרות ← כללי ← מנהל התקנים חיצוניים ← רשימת התקנים ← מאפשרים את "Phone Remote".
